# EMNLP-26

This repository serves as a central directory of all EMNLP'26 publications by the Webis Group.

The code and data associated with the respective papers are found in the repositories linked below:

* Leandra Fichtel, Janek Prange, and Henning Wachsmuth. **Attribute-Based Activation Steering of LLMs for Group-Specific Explanation Generation.** [[paper](https://aclanthology.org/2026.emnlp-main.127.pdf)] [[code](https://github.com/webis-de/emnlp26-group-specific-explanations)]
* Klara M. Gutekunst, Yaron Winter, and Martin Potthast. **The Impostors Method as a Statistical Test for Authorship Verification With Large Language Models as Sampling Source for Hard Negatives** [[paper](https://downloads.webis.de/publications/papers/gutekunst_2026b.pdf)] [[code](https://github.com/webis-de/emnlp26-impostors-method-llm-hard-negatives)]
* Maximilian Spliethöver, Jannes Lötfering, Dominik Bachmann, Alexander Espig, Willem Zuidema, Katrin Schulz, Henning Wachsmuth. **Cultural (In)Competence: Investigating Culture-Specific Stereotype Detection Capabilities of LLMs** [[paper available soon]()] [[code](https://github.com/webis-de/cultural-stereotype-detection)]
* Maja Stahl, Timon Ziegenbein, and Henning Wachsmuth. **Generating Constructive Feedback on Stories via Reinforcement Learning** [[preprint](https://arxiv.org/pdf/2609.04824)] [[code](https://github.com/webis-de/emnlp26-rl-feedback)]
